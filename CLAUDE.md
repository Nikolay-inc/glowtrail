# Проект: Glowtrail — мобильная и веб-головоломка

- Стек: TypeScript, Phaser 3, Vite, Capacitor 7 (iOS и Android; Capacitor 8 требует Node 22).
- Игра должна работать в мобильном браузере: касания, вертикальный экран 9:16, масштабирование под любой экран.
- Без внешних картинок: на этапе прототипов вся графика — простые фигуры и цвета в коде.
- Уровни храним в JSON, логику игры держим отдельно от отрисовки, чтобы её можно было тестировать.
- После изменений запускай сборку и тесты; не оставляй проект в нерабочем состоянии.
- Отвечай и комментируй на русском.

## Коммиты

- Сообщения коммитов — только на английском.
- Формат: `<type>: <short summary>`, где type — `feat` (новая возможность) или `fix` (исправление). Примеры: `feat: add hint button`, `fix: stash tap on empty slot`.
- Заголовок короткий (до ~60 символов), в повелительном наклонении, без точки в конце. Подробности при необходимости — в теле коммита, тоже на английском.

## Команды

- `npm run dev` — локальный сервер (http://localhost:5173, `?level=N` открывает уровень сразу)
- `npm test` — тесты Vitest (`tests/`)
- `npm run verify` — таблица метрик по всем уровням; проверяет решаемость, звёзды, колоды облегчения, актуальность метрик, светлячков и кривую (1–10 — таблица в `scripts/verify.ts`, 11–30 — план мира `src/levels/curve.ts`, «пила» в десятках)
- `npm run ease` — пересчитать колоды незаметного облегчения (`easeDecks`) и метрики сложности (`metrics`) в JSON; запускать после любого изменения уровня
- `npm run gen -- --count 300 --size 5x6 --features lantern,rock,water,firefly,jump,turnbridge,fade --seed N [--reserve 2-7] [--goal fireflies] [--min-roads 10] [--max-rating 3]` — генератор кандидатов в `generated/` (в git не идёт; воспроизводится по seed). Отбрасывает нерешаемые, с 1 решением, «скучные» (тупиков < 12%), требующие «отложить», с недоступными светлячками, слишком тяжёлые для решателя (> 60 000 состояний) и те, где новый элемент не нужен (без прыжков не решается; без поворотного моста не решается; гаснущий фонарь отнимает решения)
- `npm run sim-economy` — симуляция первых 2 часов среднего игрока (`src/core/economySim.ts`: ожидаемое время уровня с поражениями, средние звёзды и светлячки, покупки по списку желаний `WISHLIST`, не больше одного объекта и одной покупки между уровнями): когда восстанавливается каждый объект деревни и покупается каждая вещь. Падает, если в первый час между целями больше 5 минут, деревня восстановлена раньше уровня 26 или после мира 1 не осталось дорогих покупок (≥ 3 вещи от 200 монет, среди них улучшение). Тест проверяет то же самое
- `npm run pick` — подбирает уровни 11–30 из кандидатов под план мира и пишет `src/levels/valley/NN.json` (`--dry` — только показать, `--only 14,20` — перевыбрать эти)
- Редактор уровней: `npm run dev`, затем `http://localhost:5173/?editor=1` (только при разработке, в сборку не попадает)
- `npm run build` — проверка типов и сборка в `dist/` для Pages (base `/glowtrail/`)
- `npm run build:app` / `cap:sync` / `cap:ios` / `cap:android` — сборка для приложения (base `./`, mode `app`, ключи из `.env.app`) и открытие нативного проекта
- `npm run icons` — иконка и заставка: `scripts/make-icons.ts` рисует SVG Lumo → `assets/*.png`, `capacitor-assets` нарезает размеры
- Деплой: пуш в `main` → GitHub Actions (`.github/workflows/deploy.yml`) → https://nikolay-inc.github.io/glowtrail/

## Устройство кода

- `src/core/` — чистая логика без Phaser: `types.ts`, `level.ts` (разбор JSON), `game.ts` (правила, неизменяемое состояние), `solver.ts` (поиск в глубину, подсказки, предел решений 500, светлячки, `solutionOf`), `difficulty.ts` (метрики и рейтинг), `generator.ts` (генератор уровней), `economy.ts` (валюты, деревня, прокачка, скины, награда дня, подсказки), `economySim.ts` (симуляция экономики).
- `src/meta.ts` — мета-игра поверх SaveService (начисление/трата, лог); `src/ui/meta.ts` — значки монеты и света, счётчики, панель вкладок, награда дня; `src/ui/skins.ts` — что надето и стили дороги/арки.
- Уровни — по мирам: `src/levels/<мир>/NN.json` (порядок — по имени файла), `src/levels/worlds.ts` — миры (id, название, тема карты, уровни; код готов к трём мирам), `index.ts` — реэкспорт. Новый уровень: положить JSON в папку мира, затем `npm run ease` и `npm run verify`. Id уровня постоянный (`valley-07`), по нему хранится прогресс; `level.num` — номер по порядку (обучение, подсказки).
- `src/levels/curve.ts` — план мира «Долина» 11–30: роль в десятке, целевой рейтинг, размер, элементы, ночь, название-заготовка.
- `src/editor/editor.ts` — редактор уровней (HTML поверх игры): рисование клеток (мост — повторный тап поворачивает, гаснущий фонарь — меняет число), цель «только светлячки», колода (с прыжком), «Проверить», «Сыграть» (GameScene с `{ custom }`, прогресс не пишется), «Показать решение», «Экспорт JSON», «Загрузить».
- `src/ui/` — отрисовка (поле, карточки плиток, кнопки, Lumo), `src/scenes/` — экраны Phaser (меню, уровень, статистика).
- `src/storage.ts` — прогресс и лог событий поверх SaveService, `src/audio.ts` — синтезированные звуки.
- `src/core/geo.ts` — решатель для бесконечной колоды и поиск пути генератора (геометрия + часы уровня), `src/core/tiles.ts` — как плитка ложится на поле и «часы» уровня (`TimeState`: число поставленных плиток и когда зажглись гаснущие фонари; `timeKey` — для запоминания в решателях), `src/core/portal.ts` — стороны арки, где конец дороги, число на замке.
- `src/strings.ts` — тексты обучения, целей и подсказок (`t('key', {n})`); EN/UK добавятся рядом. Остальные тексты интерфейса пока в коде экранов.
- `src/tutorial.ts` — подсказки Lumo (каждая один раз, `profile.tipsSeen`), состояние обучения, «не больше одного окна и не два подряд». `src/ui/LumoTip.ts` — облачко подсказки. `src/scenes/IntroScene.ts` — вступление.

## Правила механики (как реализовано)

- Плитки относительны направления дороги. Каждая плитка занимает клетку(и) впереди конца дороги; поворот занимает клетку впереди и разворачивает дорогу.
- Мост ставится только на воду, вода проходима только мостом. «Прямо x2» не перепрыгивает препятствия.
- «Прыжок» (`jump`, с уровня 15): перелетает через одну клетку (камень, воду, фонарь, мост, свою дорогу — не арку) и встаёт на следующую; приземлиться можно только туда, куда встала бы обычная плитка. Перепрыгнутая клетка на дорогу не попадает: фонарь не зажигается, светлячок не собирается.
- Поворотный мост (`-` горизонтальный, `|` вертикальный на старте, с уровня 21): после каждой поставленной плитки поворачивается на 90° («отложить» и обмен время не двигают). Пройти можно только вдоль моста и только прямо (повернуть на мосту нельзя, мост-плитка не нужна). Мост под дорогой больше не крутится. Следующее положение показано полупрозрачно.
- Гаснущий фонарь (цифра `2`–`9`, с уровня 25): после зажигания горит N ходов (число на табличке уменьшается с каждой плиткой); последняя из N плиток ещё может войти в арку. Погас до арки — снова не зажжён, пройти через него второй раз нельзя → поражение.
- Цель уровня (`goal`): `classic` — арка и фонари; `fireflies` — арки нет, победа при сборе последнего светлячка (с уровня 18). Карточка цели, строка цели и экран «Почти!» меняются под цель.
- Выход закрыт, пока дорога не прошла все фонари; «прямо x2» не может пройти сквозь выход.
- Лоток — 3 верхние плитки колоды; освободившийся слот добирается из колоды; рядом мелко видно следующие 2 плитки.
- Слот «отложить» на одну плитку. Тап по пустому слоту убирает туда крайнюю левую плитку лотка, тап по занятому — меняет её с крайней левой. Перетаскивание: плитку лотка на слот — отложить/обменять; отложенную на плитку лотка — обмен, вверх на поле — поставить. Отмена — 1 раз за уровень.
- Поражение — нет ни одного осмысленного хода (отложить считается ходом, только если в колоде остались плитки).
- Звёзды: пороги `stars.two` / `stars.three` — сколько плиток осталось; 3 — от (макс. остаток − 1), 2 — от половины макс. остатка (вниз). Формула — `starThresholds`, verify сверяет JSON с ней.
- Кривая сложности: размер поля, запас (плиток сверх минимума) и число решений. Новые элементы — по одному, после сложного уровня — лёгкий.
- Метрики (`src/core/difficulty.ts`): решений (до 500), минимум плиток, запас, доля тупиковых ходов (случайные допустимые ходы по выборке 600, детерминированно), рейтинг 1–10 = 1 + тупики (до 4) + мало решений (до 2, на коротком пути меньше) + малый запас (до 1,5) + длина пути (до 1,5) — `ratingOf`.
- Уровни-знакомства (первая встреча механики: 11, 15, 18, 21, 25 — `intro` в плане) и все «лёгкие» — рейтинг ≤ 3 и решений ≥ 10 (`mustBeEasy`; verify — ошибка, тест, pick отбирает только такие).
- Мир «Долина», 30 уровней: 1–10 — обучение (не трогаем); 11–30 — что-то новое каждые ~5 уровней: 11–14 светлячки, 15–17 прыжок, 18–20 цель «только светлячки», 21–24 поворотный мост, 25–29 гаснущий фонарь, 30 — испытание «всё вместе» (`NOVELTY` в `curve.ts`, verify и тест проверяют). В каждом десятке «пила»: 1–3 лёгкие, 4–7 средние, 8 передышка (рейтинг ≤ 3 и решений ≥ 10), 9 сложнее, 10 «испытание»; рейтинг растёт примерно с 2 до 6, испытания до 7; уровней с 1 решением нет; поле до 6x8. Прогресс хранится по id — переделка уровней его не теряет.
- Светлячки (`F`, с уровня 11): дорога через клетку собирает светлячка, собирать не обязательно (кроме цели `fireflies`), на звёзды не влияют. Счётчик в строке цели и на экране победы, лучший сбор — `progress.fireflies`. verify требует, чтобы все светлячки уровня можно было собрать за одну победу. Первая встреча — карточка правила «Светлячки» (по содержимому уровня, `rulesFor`).
- Формат уровня: `grid` — строки поля (`.` пусто, `#` камень, `~` вода, `L` фонарь, `E` выход, `S` старт, `F` светлячок, `-`/`|` поворотный мост, `2`–`9` гаснущий фонарь), `goal` (`classic` по умолчанию / `fireflies` — без `E`), `startDir` N/E/S/W, `deck` сверху вниз (плитки: straight, straight2, left, right, bridge, jump), `tutorial`: `place` (рука показывает нужную плитку) или `stash` (рука показывает «отложить»), `tip` — подсказка Lumo в начале уровня (`lantern`, `side_entry`, `stash`, `water`), `tileSet` — бесконечная колода из набора, `allowStash: false` — слот «отложить» скрыт, `night: true` — ночной уровень (затемнено только поле), `easeDecks` — колоды облегчения и `metrics` — метрики сложности (оба генерирует `npm run ease`).

## Мета-игра и экономика (Р3а)

- Монеты: первое прохождение уровня — 10 + 5 за звезду, переигровка — 5 за каждую новую звезду; ещё — награда дня и объекты деревни. Хранятся как `coinsEarned − coinsSpent`. Тратятся на прокачку и скины.
- Свет: 1 звезда = 2 света, 1 светлячок = 1 свет — по лучшему результату уровня, не хранится отдельно: `lightEarned(progress) − цена восстановленных объектов`. Переигровка добавляет только разницу. Тратится на деревню.
- Деревня (`VillageScene`, вкладка «Деревня»): 10 построек по цене (колодец 10, пекарня 12, мастерская 12, мельница 12, мост 16, сад 20, часовня 20, площадь 20, дом Lumo 22, маяк 24 — всего 168 света), восстанавливаются по порядку; рисунки — `src/ui/village.ts` (`drawBuilding`: черепица, трубы, наличники, заборчики, фонари; до восстановления — тёмные и обветшалые). Раскладка рядами по свободной высоте экрана (`LAYOUT`, масштаб от высоты), под каждой — название и ценник (отдельный слой поверх построек); тап по невосстановленной — плашка «Название · награда · цена» (с кнопкой «Восстановить», если это следующая и света хватает). Анимация: искры → свет в окнах, дым, свечение, жители, лопасти мельницы и луч маяка крутятся. Ближайшая цель всегда сверху; точка на вкладке, когда хватает света. Уровни не блокирует.
- Прокачка (`WorkshopScene`, из деревни; карточки: иконка слева, заголовок и описание одним блоком, уровни-точки, цена справа): «Отложить» 1 → 2 слота (300), «Поворот плитки» 1 (из деревни) → 2 → 3 заряда (115, 420), «Фонарик» 2 → 3 → 4 → 5 плиток наперёд (45, 160, 380). Подсказки: 3 бесплатные в день + запас (3 у нового игрока), покупка за 30 монет, «за рекламу» — заглушка (выдаёт подсказку). На уровнях 1–4 и в обучении подсказки бесплатны; облегчение и пропуск — всегда бесплатно.
- Правила: `GameState.stash2`/`stashSlots` (второй слот, действия `stash {to}`, `placeStash {from}`, `swap {with}`), `rotations` и действие `rotate` (прямо → направо → налево → прямо; «прямо x2», мост, прыжок не поворачиваются). Решатель и подсказка знают второй слот (`stashSlots`), поворот не учитывают.
- Скины (`ShopScene`, вкладка «Магазин»): костюмы (бывшие 8 аватарок, меняют Lumo на поле; 0–1 сразу, 2–3 выбор в окне знакомства или покупка), формы фонаря, дорога (светящаяся, лунная, светлячковая, закатная, северное сияние, камешки, доски), арка (портал, лунная, закатная, каменная, цветочная). В профиле — надетый костюм и кнопка «Сменить» (в магазин). «Особые» (Золотой костюм, корона, звёздная пыль, золотая арка) пока недоступны (Р4); часть — из деревни и награды дня.
- Награда дня: календарь на 7 дней (монеты, подсказки, на 7-й — костюм «Янтарный» или 150 монет), пропуск дня — заново с 1-го. На карте — кнопка-подарок с отметкой, пока награда не забрана; окно открывается само, как только можно (`dailyPrompt`; после другого окна ждём `DAILY_GAP_MS` = 4 с, проверка каждые 1,5 с), или по тапу на подарок.
- Лог: `currency_earn`, `currency_spend` (`currency`, `amount`, `source`/`item`), `village_restore`, `upgrade_buy`, `skin_buy`, `daily_reward`.

## Музыка

- `src/audio/music.ts` (`NightMusic`, `music`): генеративная ночная музыка на WebAudio без файлов — аккорды-подушки (раз в 8–12 с), редкие колокольчики по пентатонике, низкий гул, сверчки и ветер, общий ревербератор (сгенерированный импульс). Громкость 25%. Постоянные узлы создаются один раз, аккорды и колокольчики отключаются по `onended` (тест `tests/music.test.ts`: 10 минут — узлы не растут).
- `src/audio.ts`: общий AudioContext со звуками; `initMusic` — старт после первого касания (iOS), плавное появление 3 с; сворачивание — пауза, возврат — плавное продолжение (`suspendAudio`/`resumeAudio`); `duckMusic` — приглушение на 2 с на победе; `setMusicMood('warm')` — в деревне и мастерской теплее. Переключатели «Музыка» и «Звуки» в профиле (`progress.music`, `progress.muted` — настройки устройства).

## Карта мира (меню)

- `src/scenes/MenuScene.ts` (сцена `Menu`): вертикальная тропинка через долину — холмы, деревья, речки (перед первым уровнем с водой и во втором десятке) с мостиками, дома без огней (у каждого 5-го уровня и дом Lumo внизу; «зажжём» в Р3). Раскладка кружков — чистая `mapLayout`.
- Пройденные уровни светятся, под кружком звёзды (или значок пропуска), у уровней со светлячками — огонёк; текущий пульсирует, рядом Lumo; «испытания» (10, 20, 30 — `isChallenge`) — кружки побольше с короной.
- Прокрутка пальцем с инерцией, колесом, стрелками; при открытии текущий уровень — посередине между шапкой и кнопкой «Играть». Шапка (профиль, «Войти», мир, монеты и свет, подарок награды дня) и низ («Играть», вкладки Карта / Деревня / Магазин / Профиль — `addTabBar`) — на своих сплошных подложках с мягким краем, карта прокручивается под ними. Музыка, звуки, вибрация, статистика и «Как играть» — в профиле.

## Цель и обучение

- Выход — арка-портал, симметричная со всех сторон, с 4 огоньками-входами; огонёк загорается, когда конец дороги рядом с этой стороны. На арке замок с числом незажжённых фонарей; при 0 замок открывается. Фонарь зажигается сразу, когда через него проходит дорога.
- В начале каждого уровня — карточка цели на 1,5 с; сверху всегда строка цели (арка + фонари «зажжено/всего»).
- Карточки правил (`src/rules.ts` — сценарии, `src/scenes/RulesScene.ts` — показ): живая анимация на мини-поле настоящей логикой игры — ошибка (красный крестик) и правильное решение. «Дорога к двери» — перед уровнем 1, «Фонари» — 3, «Камни» и «Вход с любой стороны» — 4, «Река» — 8 (`RULES_BY_LEVEL`), каждая один раз (`rule:*` в `tipsSeen`). В меню «Как играть» — все карточки и «Пройти обучение с начала». Тест прогоняет каждый сценарий: неудачи действительно не встают, финал — победа.
- Фонарь стоит на тёмном постаменте с оранжевым ободком и горит белым в оранжевой рамке — чтобы не сливаться с жёлтой дорогой.
- Карточки правил по содержимому уровня (`rulesFor`): «Светлячки», «Прыжок», «Только светлячки» (`ffgoal`), «Поворотный мост», «Гаснущий фонарь» — при первой встрече. На уже пройденном (или пропущенном) уровне карточек нет (`pendingRules`), кроме режима «Пройти обучение заново».
- Иконки плиток (`drawTileIcon`): одна толщина, линия из одной точки снизу, наконечник — точно на конце линии по касательной, повороты центрированы. Превью следующих плиток — ряд у правого края колоды.

## Живое поле (BoardView)

- Палитра «Долины» — сумерки: тёмный луг и вода, сумеречное небо с чёрными холмами (`addBackground(scene, { evening: true })`). Над полем всегда полумрак (`BoardOptions.dark`, у ночных уровней гуще); дорога — лента света (сияние, тёплая полоса, яркая сердцевина, искорки), она освещает траву вокруг — Lumo несёт свет в поле.
- Украшения пустых клеток (травинки, цветы, камешки) — случайные, но стабильные от id уровня; трава колышется в `update`, прячется под дорогой. Вода — волны и блики; светлячки летают по кривым; днём изредка пролетают бабочки, над полем — тёплые искры.
- Lumo стоит на конце дороги и шагает по каждой плитке (~250 мс, подпрыгивает, фонарь покачивается; прыжок — высокая дуга), свет растекается по новой клетке огоньком на краю, с искрами и мягким «бум» (`sfx.thump`), в приложении — лёгкая вибрация на шаг (`haptics.step`). Финал — волна света по дороге зажигает фонари, Lumo входит в арку (у цели «светлячки» — светлячки кружат вокруг него).
- Серия без отмен: с 3-го хода подряд — искры по дороге (`board.sparkle`) и нарастающая нота (`sfx.streak`); отмена сбрасывает.
- Уровень 4 учит входу в арку сбоку (снизу камень, сверху край поля) — verify это проверяет.
- Первый запуск: вступление (~12 с, пропуск тапом) → уровни 1–3 с карточками правил и подсказками → карта мира → окно «Как тебя зовут?». Предложение войти — после уровня 6. В меню кнопка «Как играть» (карточки правил, оттуда же — пройти обучение заново: карточки и подсказки покажутся снова, прогресс не трогается).
- Подсказки Lumo: после первой ошибки — «назад», бездействие 15 с или 2 поражения — «подсказка», тупик — «заново», «отложить», первый поворот (иконки в лотке поворачиваются), камень, вода (на первом уровне с водой подсвечивается мост), фонарь, вход сбоку, перетаскивание. Реплика у закрытой двери — при каждой попытке и в окне тупика.
- Плитку можно перетащить на конец дороги (подсвечивается зона сброса и предпросмотр); мимо — плитка возвращается. Предпросмотр рисует настоящий изгиб дороги; на конце дороги — конус света в направлении движения.
- В логе: `tutorial_step`, `tip_shown`, `tap_place`, `drag_place`, `door_locked_attempt`, `fireflies_collected` (на победе, `fireflies`/`firefliesTotal`), `tile_jump_used`, `bridge_rotated_blocked`, `lantern_expired` (`tile` — номер плитки); `start` содержит метрики уровня (`rating`, `trap`, `roads`) и `goal_type`.

## Защита от застревания

- Отмена хода без ограничений: можно отменять много ходов подряд, до старта.
- Уровни 1–4 без лимита плиток (`tileSet` в JSON): плитки случайные из набора, но раздача «честная» — пока до выхода можно дойти, в лотке есть ведущая к нему плитка. Поражение только в тупике. Звёзды по отменам: 0 — 3, 1–2 — 2, больше — 1.
- Счётчик поражений подряд на уровень (`lossStreak`), сбрасывается победой.
- «Подсказка» бесплатна и без ограничений: следующая верная плитка по решателю; если из текущего положения не выиграть — предлагает откатиться к ближайшему решаемому состоянию. После 2 поражений подряд кнопка пульсирует.
- Экран «Почти!»: фонари x из y, расстояние до выхода, «+3 плитки» (уровни с колодой, 1 раз за попытку), «Отменить ход», «Заново».
- После 2 поражений подряд колода незаметно получает +2 плитки (`easeDecks[1]`, считаются заранее), после 4 — кнопка «Пропустить уровень»; пропущенный уровень отмечен в меню и остаётся доступным.
- События в логе: `hint_used`, `extra_tiles`, `auto_ease`, `level_skipped` (плюс `start`, `win`, `lose`, `abandon`, `session`).

## Аккаунт и облако (Supabase)

- Играть можно без аккаунта. Кнопка «Войти» всегда в правом верхнем углу меню; после уровня 6 гостю один раз показываем «Сохрани прогресс» (регистрация/вход, можно «Позже»; флаг `profile.authPrompted`). Аккаунт: регистрация, вход, «забыли пароль», смена пароля, выход, удаление аккаунта.
- Код: `src/cloud/` — `account.ts` (Supabase Auth), `sync.ts` (облачное сохранение), `merge.ts` (слияние, чистые функции), `validate.ts` (поля и тексты ошибок), `store.ts` (таблица `saves`). Формы — `src/ui/AuthDialog.ts` (обычный HTML, не Phaser).
- Ключи: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в `.env.production` (публичные, доступ защищён RLS). Без них вход выключен, игра работает локально. Локальные ключи — в `.env.local` (не коммитится).
- База: `supabase/001_init.sql` — таблица `saves` (одна строка на игрока, RLS «только своё»), функция `delete_my_account()`; `002_grants.sql` — права роли authenticated на таблицу (для проектов, где они не выдаются сами).
- Проект: `https://tsxdbfjlrdyyvemhpqbz.supabase.co`. **На время плейтеста подтверждение почты выключено** (Authentication → Sign In / Providers → Email → Confirm email): регистрироваться можно с любой почтой. Перед публичным запуском — включить обратно и подключить свой почтовый сервис (встроенная почта Supabase — всего несколько писем в час) или платный тариф. Решение за Николаем.
- В облако уходят профиль и прогресс, лог событий остаётся на устройстве. При входе облако и локальное сливаются (звёзды/уровни — максимум), дальше изменения пишутся в облако с задержкой 1,5 с. При выходе устройство возвращается к чистому гостю.

## Сохранение и профиль

- Всё сохранение идёт через `src/save/SaveService.ts` (`load` / `save` / `update` / `reset`): один объект `{ version: 5, profile, progress, economy, log }` под ключом `glowtrail.save`. `economy` — `src/core/economy.ts` (`normalizeEconomy`), в облако уходит вместе с профилем и прогрессом; слияние — `mergeEconomy` (счётчики — максимум, покупки и деревня — объединение).
- `progress` — по id уровня: `unlocked` (список id; уровень также открыт, если предыдущий пройден или пропущен — `isUnlocked`), `stars`, `attempts`, `lossStreak`, `skipped`, `fireflies`. В логе `level` — тоже id.
- `profile`: `playerId` (UUID, создаётся один раз — для будущей привязки облачного аккаунта), имя (до 16 символов, пусто → «Путник»), аватарка 0–7 (= надетый костюм), серия дней подряд, число подсказок. Логика — `src/profile.ts`, рисунки аватарок — `src/core/avatars.ts`.
- Имя спрашиваем мягко после первой победы на уровне 3 (`ASK_NAME_AFTER_LEVEL`), его можно пропустить. Экран «Профиль» — кнопка с аватаркой в углу карты мира.
- Хранилище подменяемое (`setBackend`): сейчас localStorage, потом облако. В тестах — `memoryBackend()`.
- Миграция цепочкой v1 → v2 → v3 → v4 → v5 (v5: экономика; монеты за уже пройденные уровни задним числом, аватарки, открытые звёздами, остаются костюмами; облако старой версии — так же): v1 — старые ключи `glowtrail.progress.v1` / `glowtrail.log.v1` (не удаляются), v2 → v3 добавляет профиль, v3 → v4 переводит номера уровней 1…N в id `valley-NN` (прогресс, лог; облако старой версии нормализуется при слиянии). При изменении формата — поднять `SAVE_VERSION` и добавить шаг в `migrate`.
