Создай в корне этого репозитория (glowtrail) веб-прототип головоломки Glowtrail (рабочее название, фонарщика зовут Lumo) на TypeScript + Phaser 3 + Vite.

Механика:
- Поле из клеток (5x7 по умолчанию, размер задаётся в уровне). На поле: старт с фонарщиком (и направлением взгляда), выход, фонари (дорога должна пройти через каждый), камни (непроходимы), вода (пересекается только плиткой «мост»).
- У уровня есть фиксированная колода плиток. Внизу экрана лоток из 3 верхних плиток колоды, счётчик оставшихся плиток виден.
- Плитки относительны текущего направления дороги: «прямо» (1 клетка), «прямо x2» (2 клетки), «поворот налево», «поворот направо», «мост» (прямо через 1 клетку воды).
- Игрок нажимает на плитку в лотке — она сразу пристраивается к концу дороги. Перед нажатием показывай полупрозрачно, куда она ляжет (при наведении / долгом нажатии). Нельзя ставить плитку, если дорога уйдёт за поле, в камень, в воду без моста или на уже проложенную дорогу — такая плитка в лотке серая.
- Слот «отложить»: можно убрать одну плитку из лотка в запас и позже достать. Кнопка «отменить ход» — 1 раз за уровень.
- Победа: дорога дошла до выхода и прошла через все фонари. Тогда фонарщик идёт по дороге с анимацией и зажигает фонари. 3 звезды, если осталось много плиток.
- Поражение: плитки кончились или ни одну нельзя поставить. Кнопка «заново».

Уровни:
- 10 уровней в JSON с плавным ростом: уровни 1–2 — обучение без текста (подсветка нужной плитки, рука-указатель), дальше появляются фонари, камни, вода и мост.
- Напиши решатель (поиск в глубину с учётом лотка из 3 и слота «отложить») и команду npm run verify, которая проверяет, что каждый уровень решаем, и печатает число решений (мало решений = сложный уровень).

Техническое:
- Вертикальный экран, работает пальцем и мышкой, крупные кнопки. Простая приятная графика из фигур и мягкие анимации — игра должна ощущаться живой.
- Прогресс в localStorage. Простой лог событий (уровень начат / пройден / проигран, время, число попыток) и экран «Статистика» с кнопкой «Скопировать».
- Настрой деплой на GitHub Pages через GitHub Actions, чтобы прототип открывался по адресу https://<логин>.github.io/glowtrail/ (base: '/glowtrail/' в vite.config).
- Напиши тесты на логику размещения и победы (Vitest).
